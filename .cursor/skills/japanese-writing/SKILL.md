# 日本語の書き方

書く前にこのファイルを読む。Gemini や人間の指摘は、文を直した同じ変更で、ここに一般則を足す。チャットに残して終わらない。既に書いてある指摘を、次の文で繰り返さない。

設計文書の契約用語を、利用者向けの文へそのまま持ち込まない。設計を変えるときは設計 PR が先で、このスキルはコメントの言葉を決める。

## 文の形

- 常体。敬体を混ぜない。翻訳調（「〜することとする」「〜を行う」の連発）にしない
- `。` と `.` は、文末にも文の途中にも置かない。README の地の文だけ `。` を許す
- 補足は（）。並列は、。前の節が進行・状態なら「しており」「ており」でつなぐ
- 「している。もう一方は」は禁止。「しており、もう一方は」
- テストの前提・手順・期待も同じ。メソッド名の「こと」で終えてよい

## 言葉

利用者とコメントの読者が、設計を開かなくても意味が取れる言葉を使う。

| 書かない | 書く |
| --- | --- |
| 哨兵 | ワークフォルダ全体のロック |
| キャンセル、待ちを切る | 取り消し、待ちを取り消す |
| サイドカー | ステージングファイル（`.txnew`） |
| 本物は触らない（残るのがジャーナルのとき） | ジャーナルは残る |
| 優先した全体の結果 | 優先順位で選んだ全体の結果 |
| 成り行き | 扱い |
| 全部（同じファイルが「すべて」のとき） | すべて |
| 作っている（外部が既に書いたとき） | 外部で既に作成されている |
| 足している（外部がファイルを足したとき） | 追加されている |
| か（真偽を聞く述語で、隣が「かどうか」のとき） | かどうか |
| 〜で、（状態を言い切って次へ続けるとき） | 〜であり |
| と競合（動詞が欠けているとき） | と競合する |
| この呼び出しの失敗は呼び出し側へ返す | 呼び出し側が元の例外を返す |
| 予約する（すでに予約が終わっているとき） | 予約した |
| 〜への上げ | 〜に上げる |
| summary と remarks で止めている対象が違う | メソッド名・summary・remarks の主語を揃える |
| 検出条件より広い言い方（「外から変わった」など） | 実際の判定（記録との差） |
| 空として（意味が空文字列のとき） | 空文字列として |
| ストリームを組む | ストリームを介す、用意する、組み立てる |
| 字面（設計の言い方をコメントへ持ち込むとき） | 渡したパス（解決前） |
| その先の無い（指示語と「無い」が続くとき） | 先行詞を残す（ジャンクションの先に無い） |
| 失敗の期待でワークフォルダにファイルは無い | 実際の判定（外は空、`.txnew` が無い） |
| 短い名前（8.3 の別名） | 短縮名 |
| 一つの Path を「A と B である」 | A に B を付けたもの |
| 渡した無い | 渡したまだ無い |
| 失敗を投げる（例外のこと） | 例外を投げる |
| 辞書順（比較の条件を落とすとき） | パスの大文字小文字を無視した辞書順 |
| 行を返す／置き換える行（戻り値や引数が index のとき） | 位置を返す／置き換える行の位置 |
| 移動元の元（など「元」の重ね） | 移動元、または元のファイル（どちらか一方） |
| パスに付いている行 | そのパスの行、パスについての行 |
| 括弧の並列で片方だけ節 | 同じ種類の名詞で揃える |
| 「A、または B」で片方が名詞 | 両方を節にする |
| 初出の呼び方だけ（中身が無い） | ファイル名を同じ文に書く |
| 〜のあと（終わった動作が無い） | 何を終えたあとかを書く |
| 実体を作る適用（コミットの適用と重なる） | 実体作成 |
| サイズだけを Add の目的語にする | 1MiB の a.txt を Add（ファイルを書く） |
| 「同じ〜」に先行詞が無い | 指定した、仕込んだ、その |
| 注入の責務を「受ける」 | 担う、または扱う |
| true と書く（bool の XML） | `<see langword="true"/>` |
| 終えたあと（完了と「あと」が重なる） | 終えたなら |
| 同じ名前を作る（名前が目的語に見える） | 同じ名前のディレクトリを作る |
| ことを付けたコピー | その状態を付けたコピー |
| 作成済みの操作（操作自体が作成済みに読める） | 作成済みを記録した操作 |
| 消す／残す summary に主体が無い | 同ファイルの既存文に合わせ、Recover で消す／残す |
| 空のワークフォルダ | ワークフォルダだけがある |
| 新しい版が残したもの（行為者を略す） | 新しい版のライブラリが残したもの |
| パスやジャーナルを持つワークフォルダ | そのジャーナルがあるワークフォルダ |
| 例外になる場所より狭い言い方 | 例外になる場所を漏れなく書く |
| テスト期待でパスを分ける（sub と a.txt） | 実際に書いた相対パス（sub/a.txt） |
| 前提で結果を「書き換えている」 | 書き換えてある |
| ファイルの ACL や属性をメタデータと呼ぶ | 列挙するか「それら」で受ける（メタデータフォルダと分ける） |
| 括弧内の 。 | 、 |
| 書きかけを消す主体が無い | メソッド名を主語にする |
| ステージ中（状態を体言で止めるとき） | ステージしている |
| しるしが使われている | しるしが使用中 |
| ワークフォルダ全体を待つ | ワークフォルダ全体のロックを待つ |
| 排他にした意図ロックのディレクトリ | 意図ロックを排他にしたディレクトリ |
| remarks が「できない」の制限を summary で「させない」 | 同じ「できない」 |
| ThrowIf の summary を「確かめる」で止める | 拒否する、またはできない |
| ディレクトリを「置き換えの Move」にまとめる | ファイルは置き換え、ディレクトリは入れ替え |
| summary でファイルどうしも入れ替えと呼ぶ | ファイルどうしは置き換え、ディレクトリが絡むときは入れ替え |
| 機能名を否定動詞にする（置き換えない） | bool を param と同じ言い方で書く |
| 同じ退避に退けと退避を混ぜる | 退避 |
| コミット後の姿の末尾（姿に無い属性を付ける） | コミット後の姿で、末尾に足す |
| 親がこのディレクトリの操作（関係の「である」を落とす） | 親がこのディレクトリである操作 |
| 排他のあいだ（何を排他にしたか無い） | ワークフォルダ全体を排他にしているあいだ |
| 空いていると確かめる | 空いていることを確かめる |
| パスと意図のロックファイル（契約語を崩す） | パスロックと意図ロック（のファイル） |
| 行やファイルを「〜は返す」の主語にする | 条件を主語にし、返す内容を述語にする |
| 書き足すと追記を混ぜる | 追記 |
| AとBのC（AにもCが付くとき） | AのCとBのC |
| 残す例外に握るなど捨てる動詞を続ける | 伝えない例外を書く |
| 例外にする（投げる意） | 例外を投げる |
| 索引（表の中の位置を指すとき） | 位置 |
| ファイル操作とディスク操作を混ぜる | ディスク操作 |
| 失敗の理由にする（振り分けのとき） | 失敗の理由へ振り分ける |
| 1 件消す（消す対象が無い） | パスを 1 件消す |
| 前提を体言止めの並列で終える | 〜している、〜がある |
| 同じ語を重ねる（規則に合わない名前） | 規則に合わない名前の〜 |

`docs/design.md` に既にある「哨兵」は、設計の既存語として残っている。XML、README、テストの説明、新しく書くコメントでは使わない。既存コメントを直すときも置き換える。

bool を言葉で書くとき、同じファイルの param が `<see langword="true"/>` なら summary もそれに合わせる。

例外メッセージは、設計の用語に合わせる。あいまいな「中」でフォルダ自身と配下をまとめて書かない。

## レビューのあと

1. 差し替え案を、同種の文が残っていないか探してから反映する
2. その指摘が上の表や「文の形」に無ければ、個別の文ではなく一般則としてここに足す
3. 足してから `./build.ps1` に進む
